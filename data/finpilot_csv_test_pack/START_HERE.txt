FinPilot synthetic CSV test pack
Prepared for testing on 20 October 2026. All merchants and transactions are fictional.
Currency: INR. Columns: date,merchant,amount. Negative amounts are expenses.

HOW TO IMPORT
1. In FinPilot, open the Transactions tab > Import transactions > choose a CSV.
2. Click Import CSV (not Try sample data).
3. Enter the suggested current balance below and click Save balance.
4. Try a purchase of 25000, 30 days from now, with a reserve of 10000.

IMPORTANT
Imports ADD to the current database. Do not import all profiles together if you
want the isolated expected results below. Exact repeat rows are skipped.
The built-in Try sample data button only works with an empty database.
These files do not reset, delete, or replace any existing transactions.

TO TEST EACH PROFILE SEPARATELY WITHOUT DELETING EXISTING DATA
Open a VS Code terminal in the finpilot folder. Start a separate instance:
FINPILOT_DB=sample-test-01.db .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8766
Open http://127.0.0.1:8766 and import ONE CSV. To test another profile, stop this
test server with Ctrl+C, change the database name to sample-test-02.db, and restart.
Use a new database filename for each profile. Your original database stays intact.
